Detailed Description

Clase que encapsula un arreglo estatico de enteros y proporciona metodos para su manipulacion.

  • Esta clase implementa diversos algoritmos de busqueda (secuencial y binaria), algoritmos de ordenamiento (Burbuja, Seleccion, Insercion, QuickSort y MergeSort), y metodos para rellenar el arreglo con numeros aleatorios.
